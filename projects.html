Project // 01 FREAKY bread

Position: Unity Indie Game Project // Horror Interactive Concept

▸ CLICK HERE TO PLAY THE GAME (UNITY PLAY)

[ THE BRIEF // A Nightshift Invitation ]

Oof. After surviving a total meltdown of a post-graduation job hunt and collecting a mountain of rejection letters, I out of nowhere received a midnight offer from a mysterious bakery. The job description sounded like a total breeze: pack the right types and quantities of bread onto the delivery truck in a dead-silent factory at night. Simple, right? Well, wrong. The second the conveyor belt started rolling, I froze—some of the loaves were... moving? They were literally breathing in the shadows! To make it a certified nightmare, a terrifying Manager is constantly breathing down my neck, throwing furious rushes and deadly attacks. My single brain cell at that moment: frantic bread-counting, avoiding death, and punching the clock to survive. Welcome to the ultimate corporate horror.

[ BEHIND THE SCENES // The Magic Reel ]

The spark for this game came from the most random thing ever. My friend and I were doomscrolling on Instagram and stumbled upon a hilarious, oddly satisfying Reel of a guy sharing his real-world midnight shift—mechanically sorting and packing endless bread onto trays. The industrial absurdity and raw rhythm of it were so incredibly captivating! Naturally, my cracked partner-in-crime Michelle and I teamed up for our IDP course, hijacked this brainrot concept, and weaponized it into a full-fledged indie horror game for our major project.

[ TECH SETUP // Under the Hood ]

  • Engine & Architecture: Engineered entirely in Unity with all gameplay logic, player state machines, and interactive behaviors driven by modular C# scripting.
  • Animation States: Fine-tuned Unity Animator Controllers to blend seamlessly between the subtle "breathing" blend shapes of the bread, the aggressive pursuit AI paths of the Manager, and the physics-based feedback of the player.
  • Data Integrity: Implemented a real-time sorting and validation system to track packing quotas under high-pressure environments, ensuring robust collision detection and accurate inventory calculation.

Research // 02 S'pookie Bread

Position: Roblox Hackathon Project // Hardcore Multiplayer Remake

▸ CLICK HERE TO ENTER THE EXPERIENCE (ROBLOX)

[ THE EVOLUTION // The Shift Just Got Worse ]

Guess what? The legendary midnight bakery is back, but this time it’s an absolute upgrade on Roblox! We resurrected the same Reels-inspired chaos but cranked the packing nightmare up to eleven with multi-player madness and unpredictable anomalies. Every single night you clock in, the entire factory layout and shelves randomly shape-shift into something completely unhinged. The Boss is now a certified stalker—his terrifying eyes lock onto you and he literally shadows your every move (feels like he's trying to dock my pay forever). On the bright side, we hooked up a mysterious vending machine deep in the facility selling chaotic power-ups, and there's even a forbidden switch that "spawns more bread" for the greedy brave souls. Sounds like fun perks? Well, the performance review is lethal—word on the street is that four employees who missed their KPIs last shift completely vanished into the dark...

[ HACKATHON GLORY // Sleep Deprivation & T-shirts ]

We locked into this world-building and rushed to build it for the Garena Hackathon. In a brutal, sleep-deprived marathon against the clock, we pulled an all-night coding spree to birth this chaotic, multiplayer-native experience from scratch—and we actually walked away with 4th Place (Top 4)! Beyond the trophy, we walked away with a ride-or-die tech friendship. Fun fact: we were so hyped about this world that we even printed limited-edition custom T-shirts for the game, and rocking them on campus felt incredibly badass!

[ TECH SETUP // Under the Hood ]

  • Multiplayer Gameplay Logic: Scripted entirely within the Roblox Studio ecosystem using Luau, building client-server replication structures for a chaotic multiplayer environment.
  • Procedural Map Shuffle: Architected a lightweight runtime randomization engine that rearranges factory corridors, inventory shelves, and spawn points every round to massively boost replayability.
  • AI & Item Systems: Developed custom chasing behavior trees for the NPC boss and coded a transactional vending machine database mapping dynamic item buffs/debuffs to real-time triggers.

System // 03 Sashimi's Movie Store

Position: Full-Stack Web Application // E-Commerce Architecture

Deployment Note: This digital store currently lives a happy, quiet life tucked away entirely inside my local machine (firmly bound to my local database environment), running gracefully on localhost. Thus, no public URL is available—but look at the tech setup below to see how smoothly it runs!

[ WELCOME TO THE SHOP // Boutique Cinema Experience ]

Welcome to Sashimi's private cinema lounge! This is a massive, feature-rich full-stack monster we built for our IDP course. We basically packed every single e-commerce feature you could dream of into this online store: you can run wild searching your favorite titles, instantly drop them into a personalized Watchlist, simulate checkout purchases, and log into securely authenticated personal accounts.

We even threw in a "What should I watch today?" randomized smart recommendation engine! Oh, and to make it feel like a buzzing movie community, we built an interactive review portal where users can drop ratings and—the coolest part—directly upload screenshots to show off their favorite cinematic frames or share hilarious reactions.

[ TECH SETUP // Under the Hood ]

  • Full-Stack Infrastructure: Developed with a solid Java backend utilizing core Java Servlet components, served over an Apache Tomcat web server environment.
  • Database Schema & Architecture: Backed by a relational MySQL database with meticulously mapped multi-table relations (Users, Movie Assets, Orders, and User Reviews) to guarantee seamless data persistence and rapid local query performance.
  • Frontend Multimedia Stream: Built an intuitive, clean human-computer interface integrating a specialized multipart multimedia file upload module, enabling robust and validated frontend image submissions for movie screenshots.

Interactive // 04 BonsaiGarden VR

Position: URECA Undergraduate Research Program // 3DGS Reconstructions

▸ WEB-BASED INTERACTIVE PORTAL (COMING SOON)

[ INTRODUCTION // Digital Immortality ]

Conducted under the URECA Undergraduate Research Program, this study tackles the urgent need for digital preservation of cultural heritage. The core target of this project is the "BonsaiGarden"—an artifact of immense historical and aesthetic value. Compared to traditional Photogrammetry, cutting-edge 3D Gaussian Splatting (3DGS) offers a revolutionary paradigm shift in real-time high-fidelity rendering and geometric fidelity. The ultimate objective of this research is to bridge technical divides by establishing a complete, end-to-end technical pipeline from 360° real-world video capture to immersive Virtual Reality (VR) deployment.

[ TECHNICAL PIPELINE // The Methodology ]

  • Data Acquisition: Devised a custom Omnidirectional Capture Protocol utilizing high-resolution 360° cameras to perform precise spatial movement sampling across the real-world garden.
  • Data Pre-processing: Implemented custom FFmpeg and AliceVision conversion logic to unpack raw spherical video streams into equirectangular formats, which were then cleanly segmented into multi-view perspective images.
  • 3DGS Training & Optimization: Fed multi-view perspective datasets into the 3DGS optimization framework for mathematical fitting, employing advanced post-processing to eliminate floating artifacts and refine micro-foliage high-frequency details.
  • VR Integration: Losslessly imported optimized high-definition 3D spatial Gaussian splatting assets into Unreal Engine. Developed narrative-driven VR interaction mechanics, custom material shaders, and a bespoke VR headset HUD layout.

[ SIGNIFICANCE // Cultural Echoes ]

The experimental results demonstrate that this pipeline successfully masters the notoriously difficult balance between large-scale spatial environments and the micro-details of miniature bonsai trees. This narrative-driven interactive VR experience significantly reduces the distance between modern users and fragile historical heritage, opening a brand-new engineering blueprint for digital museum curation worldwide.

Future Lab // 05 Rement Narrative

Position: Interactive Dreamcore Project // Cognitive Psychology Exploration

▸ CLICK HERE TO EXPLORE THE MEMORY PROBE (CODEPEN)

[ PHILOSOPHY // Systematically Manufactured Nostalgia ]

The seed of this project was planted by a peculiar modern social phenomenon: the absolute tsunami of "Dreamcore" and fake nostalgia taking over social media. People everywhere are obsessively reposting blurry old photos—faded vintage toys, discontinued magazines, empty afternoon parks, or rainy train stations. Fascinatingly, these images stir up massive psychological waves among peers who never lived them, convincing them that "this is my childhood memory".

As Renwu Magazine pointed out in "Why Are We Growing More Homesick for the Past?", this generational homesickness often serves as an idealized shelter to escape current anxieties. Psychologists note that while nostalgia is a warm, cozy safety nest, staying trapped in it robs us of our present and our courage to carve out paths for the future. Rement targets this pink bubble using code. I wanted to show that nostalgia is systematically manufactured. Systems average human behavior, erasing raw friction, conflicts, and painful truths to present a filtered, "harmless" version of reality. You don't love the past; you love a cinematic filter stripped of suffering.

[ DEVLOG // The CodePen Production Line ]

  • HTML Structure (The Skeleton): Structured an interactive canvas container (#stage), multi-parallax background layers (#scene), a raw retro VHS scanline/glitch layer (#fx), a mouse/touch interaction pointer (#probe), and a live-rendering diagnostic terminal (#logPanel).
  • CSS Atmosphere (The Aesthetic): Simulated true analog videotape textures using custom vignettes, noise filters, and CRT scanlines. Bound CSS global variables (like radar rotation speeds and probe coordinates) to :root to allow immediate physical interaction with JavaScript.
  • JS Interaction & Data-Driven Logic (The Engine):
    • Data Isolation: Utilized a multi-dimensional Scenes Array to decouple text strings, asset paths, entry subtitles, and hidden fragments from the main logic loop.
    • Parallax Sensing: Listened to mousemove/touchmove to inject real-time coordinates into CSS variables, producing a subtle spatial parallax effect.
    • Euclidean Radar: High-frequency executed computeNearest() every frame to calculate the Euclidean distance between the probe and hidden memory shards. As the distance shrinks, it updates the radar UI state from Detected to Locked, accelerating scan rates and directing the radar sweep line toward the target.
    • Pointer-Hold Harvest: Developed a time-accumulator bound to pointerdown. Once the holdFill bar hits 100%, it displays the memory fragment, logs the data to the diagnostic terminal, and increments state until triggering loadScene() to shift into the next memory matrix.
